Why Rafiq

One agent, fully under your control

Built for two humans and one machine — with zero cloud, zero dependencies, and the code you can read.

Bring your own key (BYOK)

Your API key is encrypted with your Windows account (DPAPI) and used only to call the provider you picked. No Rafiq account, no cloud proxy, no key ever leaves your machine.

Plan → Build → Discuss

Review a plan before approval, let the agent build in your project, or simply discuss your code. Work is streamed live, step by step.

Real filesystem, sandboxed

Point Rafiq at any real project folder. It edits only inside the chosen workspace — enforced by a path-containment check — and never touches the rest of your disk.

Every model family you like

Rafiq talks to any OpenAI-compatible endpoint, so you pick the brain — not the other way around.

Safety by default

Your history, your device

Privacy

Where does your data go?

Three destinations, two of which are your own machine.

The API key → this PC only

Encrypted with Windows DPAPI and kept in %APPDATA%\Rafiq. Used only for the request to the provider you chose.

The app → your folder only

Every file operation is checked to stay inside the folder you opened. Shell commands need your approval, dangerous ones are blocked. No telemetry, no account.

The request → the model provider

The only outbound call is to the provider you choose, carrying exactly the context you send. Nothing else leaves the machine.
