How Rafiq works

      
    

    

      
    
        
  1. Open a folder. Rafiq can only read and write inside that folder. Everything else on your disk is out of reach.
    2. 
        
  2. Add your key. Settings → pick a provider → paste an API key. It is stored on this computer only and sent straight to the provider.
    3. 
        
  3. Plan first. In Plan mode Rafiq studies the code read-only and writes a plan. Approve it to switch to Build, or just chat in Discuss mode.
    4. 
        
  4. Stay safe. Commands need your approval, dangerous actions are blocked, and every file change can be undone.
